# CampusConnect Backend (MVP)

A lightweight FastAPI + PostgreSQL backend designed for the Pakistani Student Ecosystem MVP.

## Files Created

- [`schema.sql`](file:///C:/Users/mahad/.gemini/antigravity/scratch/campus_connect_backend/schema.sql): Complete PostgreSQL DDL schema with indexes.
- [`seed.sql`](file:///C:/Users/mahad/.gemini/antigravity/scratch/campus_connect_backend/seed.sql): Initial test data (PU FCIT sample courses and resources).
- [`models.py`](file:///C:/Users/mahad/.gemini/antigravity/scratch/campus_connect_backend/models.py): Python SQLAlchemy ORM models ready for FastAPI.

## How to set up your free PostgreSQL Database (Rs. 0)

1. Go to [Neon.tech](https://neon.tech) or [Supabase.com](https://supabase.com) and sign up for a free account.
2. Create a new project (choose a region close to Pakistan, e.g., Singapore, Frankfurt, or Bahrain).
3. Open the **SQL Editor** tab in your dashboard.
4. Copy and paste the contents of `schema.sql` and click **Run**.
5. Copy and paste the contents of `seed.sql` and click **Run**.
6. Copy your database connection string (`DATABASE_URL`).
